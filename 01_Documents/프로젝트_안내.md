# GuildMaster 프로젝트

## 프로젝트 개요
중세 판타지 세계에서 길드마스터가 되어 모험가를 모집·육성하고, 길드 전력을 키워 한정된 성과 영지를 공성전으로 차지하는 PC 중심 2D 탑다운 픽셀아트 RPG + 길드 운영 시뮬레이션.

## 현재 포함된 핵심 자료
- `01_Design/GuildMaster_GDD_v0.1.docx` : 게임 기획서 초안(Word)
- `01_Design/GuildMaster_GDD_v0.1.md` : 게임 기획서 초안(Markdown)
- `02_Art/GuildMaster_Town_UI_Concept.png` : 마을 및 UI 비주얼 콘셉트 이미지
- `03_Development/Cursor_Replit_개발프롬프트.txt` : Cursor/Replit 개발 지시 프롬프트

## 확정된 핵심 설계 방향
- 시작 파티: 길드마스터 1명 + 길드원 4명(탱커, 딜러, 힐러, 마법사)
- 길드마스터는 직접 능력치 배분과 공격/마법/방어/지원 스킬 트리로 성장
- 초기 길드원 목표 최대 50명(밸런싱 가능한 설정값)
- 길드원은 훈련, 사냥, 던전 파견, 의뢰, 거점 방어에 배치
- 길드원 기본 급여 + 성과 보상, 초기 버전에는 사기/충성도/이탈 시스템 없음
- 전투는 자동 전투 + 플레이어 전술 명령의 혼합 방식
- 길드마스터의 주요 사냥/던전은 실시간, 나머지 길드원 활동은 시간 경과에 따라 자동 진행
- 성은 한정된 고정 자산이며 공성전으로 소유권이 변경됨
- 초기 버전은 싱글플레이와 AI 경쟁 길드 중심. 온라인 확장은 추후 고려
- 마을 성장은 보조 시스템이며 게임의 중심은 길드원 모집·육성·전투력 구축

## 개발 원칙
1. 기존 프로토타입이 있다면 구조·기능·조작을 먼저 확인하고 보존한다.
2. 장기 기획을 한 번에 구현하지 않는다. 작은 플레이 가능한 단계로 나눈다.
3. 1차 구현은 기본 사냥, 몬스터 3종 이상, 전투, 경험치/골드, 레벨업, UI, 피격 효과, 패배 상태를 우선한다.
4. PC 키보드/마우스를 우선 지원하고, 기존 모바일 터치 지원이 있다면 깨뜨리지 않는다.
5. 데이터 구조는 길드/길드원/성 소유권/전투 결과를 분리해 향후 확장 가능하게 설계하되, 초기에는 불필요한 서버 인프라를 만들지 않는다.
6. 콘셉트 이미지는 방향성 참고용이다. 실제 UI는 가독성과 조작성을 기준으로 구현한다.

## ChatGPT 프로젝트에 넣는 방법
ChatGPT 왼쪽 메뉴에서 새 프로젝트를 만든 뒤 이 폴더의 파일을 프로젝트 자료로 업로드한다. 프로젝트 이름은 `GuildMaster 개발`을 권장한다. 프로젝트 지침에는 아래 문장을 붙여넣는다.

> 이 프로젝트는 GuildMaster 게임 개발 전용이다. 첨부된 GDD와 콘셉트 이미지를 기준 자료로 삼고, 이미 확정된 설계를 임의로 변경하지 않는다. 나는 실제 구현을 Cursor 또는 Replit에서 진행한다. 너는 게임 기획자이자 개발 파트너로서 구현 단계, 코드, 디버깅, 테스트 항목을 구체적으로 제안한다. 장기 기능을 한꺼번에 구현하지 말고 현재 단계의 목표와 기존 프로토타입 보존을 우선한다. 대화는 한국어로 진행한다.
