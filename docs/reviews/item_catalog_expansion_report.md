### Unfinished art (must not be treated as final)

All **119** procedural icons under `assets/items/<new_id>.png` are temporary generated placeholders. Full ID list is generated by `tools/expand_item_catalog_160.py` (every new item whose icon filename equals its id and was not on `main`’s painted set). Representative IDs: `sword_ornate`, `axe_great`, `bow_long`, `armor_knight`, `gloves_plate`, `potion_hp_l`, `ore_copper`, `special_dungeon_key`, … through `special_blessing`.

**Missing finished painted art = those 119 IDs** (explicit).  
Zero items use the generic `iron_sword.png` fallback.

Pre-existing byte-duplicate assets (`magic_crystal`/`enhance_stone`, `wooden_sword`/`rusty_sword`) were not assigned as shared icons across unrelated new items; new crystal/special icons are distinct files.
