# GuildMaster 통합 프로젝트 자료

이 패키지는 GuildMaster 개발에 사용하는 기획 문서, 개발 프롬프트, 원화 및 UI 참고 이미지를 한곳에 모은 자료 패키지입니다.

## 폴더 구성

- `01_Documents/` — 게임 기획서(GDD), 프로젝트 안내, Cursor/Replit 개발 프롬프트
- `02_Assets/Spritesheets/` — 스프라이트 시트
- `02_Assets/References/` — 캐릭터·마을·전투·시설·UI 등 참고 이미지

## 개발 시작 안내

1. 이 폴더를 로컬 PC에 압축 해제합니다.
2. `01_Documents/GuildMaster_GDD_v0.1.md`와 `Cursor_Replit_개발프롬프트.txt`를 먼저 확인합니다.
3. Cursor에서 실제 게임 소스 코드가 있는 저장소/프로젝트 폴더를 엽니다.
4. 문서와 에셋을 참고 자료로 사용해 단계별로 개발합니다.

## 참고

이 ZIP은 기획·아트 자료를 단순한 폴더 구조로 통합한 패키지입니다. 실행 가능한 게임 소스 코드나 빌드 결과물은 포함하지 않습니다. 이미지 원본은 참고 자료로 보존했으며, 게임에서 바로 사용하는 런타임 경로로 자동 변환하거나 배치하지 않았습니다.
