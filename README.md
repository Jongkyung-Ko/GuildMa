# GuildMaster

판타지 길드 운영 RPG — **1단계: 마을 허브 · 시설 UI**

플레이어는 길드마스터가 되어 마을에서 시설을 이용하고, 모험가를 영입하며, 사냥터에서 자동전투를 진행합니다.

전투는 직업별 공격 애니메이션(준비→타격→복귀)과 타격 프레임 동기화 데미지를 사용합니다.  
스프라이트는 투명 PNG + NEAREST 필터이며, GitHub Pages 웹 빌드로 배포됩니다.

## 실행 방법

1. [Godot 4.3+](https://godotengine.org/download) 설치
2. Godot에서 이 폴더(`project.godot`)를 프로젝트로 열기
3. F5(실행) 또는 재생 버튼

권장 해상도: **1280×720**, 텍스처 필터 **Nearest** (프로젝트에 설정됨)

## 플레이 흐름

1. **시작 화면** → 새 게임 / 이어하기 / 설정 / 종료
2. **마을**에서 건물 클릭 → 시설 화면
3. 시설에서 영입·구매·훈련·회복·의뢰 수락 등
4. **마을로 돌아가기**로 허브 복귀
5. 사냥터 출구는 이동 메뉴만 제공 (전투는 다음 단계)

## 폴더 구조

```
01_Documents/     기획 원본 (GDD, 안내)
02_Assets/        참고 아트 원본 (수정하지 않음)
assets/           런타임 에셋 + art_reference 복사본
scenes/           타이틀 / 마을 / 시설
scripts/          게임 상태 · UI · 라우팅
data/             밸런스·아이템·모험가·의뢰 (JSON)
```

## 초기 데이터

- 군주 1 + 탱커/딜러/힐러/마법사 각 1
- 시작 골드·명성 등은 `data/balance.json`에서 조정
