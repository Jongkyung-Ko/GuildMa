# GuildMaster Art Assets

이 패키지는 이전 대화에서 제작한 GuildMaster 이미지들을 GitHub/Godot 프로젝트에 추가하기 위한 자료입니다.

## 폴더 구분
- `reference/`: UI, 마을, 길드 본부, 전투, 시설, 캐릭터 디자인 참고용 합성 이미지
- `spritesheets/`: 캐릭터 스프라이트 시트 후보

## Cursor/Godot 사용 규칙
1. `reference/` 이미지는 우선 디자인 참고 자료로만 사용합니다. 여러 화면이 합쳐진 콘셉트 이미지를 실제 게임 배경이나 단일 UI 텍스처로 그대로 사용하지 마세요.
2. `spritesheets/`의 이미지는 실제 스프라이트 시트 후보입니다. 프레임/행/열/투명 배경/캐릭터 정렬을 먼저 확인하고, 검증 전에는 게임 코드에서 사용하지 마세요.
3. 현재 전투 프로토타입의 기존 캐릭터 및 배경 PNG는 교체하거나 삭제하지 마세요.
4. 기존 프로젝트의 해상도 1280x720, nearest 필터, 픽셀아트 스타일을 유지하세요.
5. 실제 게임에 사용할 새 리소스가 필요하면 원본을 덮어쓰지 말고 별도 파일명으로 추가하세요.
6. 이번 1단계에서는 길드 허브 UI 구현에 필요한 최소 리소스만 사용하고, 나머지는 이후 상점/대장간/길드 본부 확장 단계의 참고 자료로 보관하세요.

## 권장 저장 위치
프로젝트 루트의 `assets/art_reference/` 아래에 이 패키지의 `reference/` 폴더를 복사하고,
검증된 스프라이트 시트만 `assets/sprites/characters/` 등 실제 리소스 폴더로 별도 복사하세요.
