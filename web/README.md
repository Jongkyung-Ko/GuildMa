# GuildMaster Web Emulator (Phase 2-1)

브라우저에서 마을·시설·자동전투 프로토타입을 확인할 수 있는 Godot HTML5 빌드입니다.

## 플레이 방법

1. 페이지 로드 후 클릭해 캔버스에 포커스
2. **새 게임** → 마을
3. 우측 하단 **사냥터 출구** 건물 클릭
4. **출정** → 자동전투 관전
5. 종료 후 **마을로**

조작: 마우스 클릭만 (WASD 없음). Esc로 전투 일시정지.

## 로컬 실행

```bash
cd web
python3 -m http.server 38471 --bind 127.0.0.1
# http://127.0.0.1:38471/
```
